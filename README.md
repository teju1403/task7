# Task 7 – Basic Sales Summary using SQLite and Python

##  Objective
The goal of this task is to extract and summarize basic sales data using SQL within Python, and visualize the results using a bar chart.

##  Tools & Technologies
- Python
- SQLite (via sqlite3)
- Pandas
- Matplotlib

## Files Included
- create_sales_db.py
- sales_summary.py
- sales_data.db 
- sales_chart.png

## Steps Performed
1. Created a SQLite database with a sales table (product, quantity, price).
2. Inserted sample data (e.g., Apples, Oranges, Bananas).
3. Queried total quantity and revenue per product using SQL.
